# سبيل المؤمن

موقع إسلامي شامل — صدقة جارية عن **عمرو عصام الدسوقي**

## 🌙 المميزات

- **القرآن الكريم** — قراءة مباشرة لصفحات المصحف مع إمكانية حفظ التقدم وختمة تفاعلية
- **الأذكار اليومية** — أذكار الصباح والمساء وما بعد الصلاة والنوم والاستيقاظ والمنزل والطعام والمسجد مع عدّاد تفاعلي
- **الأدعية المأثورة** — أدعية قرآنية ونبوية وللمتوفي وللخوف والحزن والفرح والرزق والسفر والمطر والتوبة والمذاكرة
- **الأحاديث النبوية** — أكثر من 200 حديث في الأخلاق والعبادات والأربعين النووية والأسرة والعلم والدنيا والقلوب والرزق ورياض الصالحين
- **الفتاوى والأسئلة** — إجابات مختصرة لأسئلة شائعة
- **مواقيت الصلاة** — تحديد تلقائي للموقع أو اختيار يدوي لمدن مصر
- **السبحة الإلكترونية** — عداد تسبيح مع حفظ التقدم
- **التقويم الهجري** — مع عرض المناسبات الإسلامية
- **ختمة جماعية** — تسجيل مساهمات الأجزاء
- **إنجازات يومية** — تتبع المهام وأسهم التقدم
- **إشعارات المتصفح** — تنبيهات لأوقات الصلاة والأذكار
- **وضع كبار السن** — تكبير الخط وتباين أعلى
- **الوضع الليلي** — واجهة مريحة للعين
- **مشاركة كصورة** — تصدير الأذكار والأدعية كصور
- **نسخ احتياطي** — تصدير واستيراد البيانات بصيغة JSON
- **PWA** — تثبيت التطبيق على الهاتف والعمل بدون إنترنت

## 🛠 التقنيات

- HTML5 + CSS3 + JavaScript
- Tailwind CSS (CDN)
- Font Awesome 6 (أيقونات)
- Google Fonts (Cairo + Amiri)
- AlQuran.cloud API (القرآن)
- AlAdhan.com API (مواقيت الصلاة)
- Service Worker + Manifest (PWA)

## 📦 الملفات

| الملف | الوصف |
|-------|-------|
| `index-12 (1).html` | الملف الرئيسي — كل HTML/CSS/JS في ملف واحد |
| `sw.js` | Service Worker للتشغيل بدون إنترنت |
| `manifest.json` | ملف PWA لتثبيت التطبيق على الهاتف |

## 📱 التثبيت على الهاتف

1. افتح الموقع في **Chrome** أو **Edge** على الموبايل
2. اضغط على قائمة المتصفح (⋯)
3. اختر **Install App** / **إضافة إلى الشاشة الرئيسية**
